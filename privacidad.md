# Política de privacidad de Clawdio Gmail

**Responsable:** Antonio Poveda Serrano, antonio.poveda.serrano@gmail.com.

**Qué datos se consultan:** los mensajes de Gmail del titular que él pide consultar o buscar, y sus metadatos (remitente, asunto, fecha, etiquetas). La aplicación solo usa el permiso de lectura de Gmail (gmail.readonly).

**Para qué:** únicamente para que el titular pueda consultar y buscar su propio correo a través de su asistente personal.

**Dónde se guarda:** la autorización de acceso se guarda cifrada en el equipo del titular. Los mensajes no se almacenan de forma permanente; se consultan cuando se necesitan.

**Con quién se comparten:** el contenido que se consulta puede enviarse a un modelo de inteligencia artificial para resumirlo o analizarlo, utilizado por el propio titular. No se vende ni se cede a terceros para publicidad.

**Conservación y borrado:** la autorización se elimina cuando el titular revoca el acceso. El titular puede revocar el acceso en cualquier momento desde la cuenta de Google, en «Seguridad → Acceso de aplicaciones de terceros».

**Tus derechos:** puedes pedir el acceso, la corrección o la supresión de tus datos escribiendo a antonio.poveda.serrano@gmail.com.

**Uso de datos de Google:** el uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.
